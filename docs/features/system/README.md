# System inventory and local reports

These workflows inspect supported Windows user-mode providers. They do not install drivers, query remote computers, optimize hardware, collect user profiles or invent sensor data.

- [Hardware and operating-system inventory](inventory.md)
- [Measured resource thresholds](monitoring.md)
- [Reviewed local JSON, CSV and Markdown export](report-export.md)

The API uses the local current-user named pipe, not HTTP. A Postman collection is not applicable. Backend fixture evidence is separate from built interface, sensor support and complete product acceptance.
