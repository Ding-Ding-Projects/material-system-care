# Reviewed local report export

Export uses an immutable server-issued system report. `system.report.review` requires `reportId`, its complete `revision`, `format` (`json`, `csv` or `markdown`), an existing local `outputFolder` and a simple `fileName` ending in `.json`, `.csv` or `.md` respectively. It returns the exact selected destination and a `reviewRevision` binding the report, format, filename, output-folder native identity and report expiry. Review performs no output-file creation. Reserved Windows device names, traversal, network folders, extension mismatch and existing targets are rejected.

`system.report.export` sends that same selection, `reviewRevision` and `confirmed:true`. A changed report revision returns `REPORT_REVISION_CHANGED`; a changed selected target returns `REPORT_REVIEW_CHANGED`; missing reports and expired observations return `REPORT_NOT_FOUND` or `REPORT_EXPIRED`. Reacquiring the exact folder handles prevents ancestor replacement during publication. The engine writes exclusively created same-folder staging storage, flushes it, checks cancellation and atomically renames its held file without replacement. A target appearing after review survives unchanged. Cancellation or publication failure removes only the held owned staging file. No pre-existing file is opened for writing.

The receipt includes exact path, format, byte count, SHA-256, report revision, UTC export time, fixture label, `overwritten:false` and `localOnly:true`. Output is bounded to 8 MiB. Path and hardware observations never enter general history or provider requests. A filename or path in the receipt is local private data, so it must not be copied into telemetry or a public capture.

JSON preserves the typed report, provider/sensor availability, counts, privacy exclusions and available resource sample. CSV is a flat seven-column schema (`Section`, `RecordId`, `Category`, `Field`, `Value`, `State`, `Reason`) covering metadata, providers, hardware, sensors, exclusions and measurements. Text beginning with spreadsheet formula markers is prefixed as text. Markdown includes equivalent rows, escapes table delimiters and HTML, and states the observation limits. Null values remain explicitly unavailable rather than silently becoming zero.

Integrated disposable fixtures export and read back all three formats, compare receipts with exact bytes, verify selection changes and occupied targets, force cancellation after staging and simulate a late target occupant. They also replace a reviewed disposable output folder to prove native-identity revision checks. This proves the local backend workflow; built interface review and capture are separate acceptance work.
