# 持久工作區基礎

本機介面由實際量度工作區開始。工作区選單直接開啟既有清理、儲存分析、重複檔案、應用程式、開機項目、防護、驅動程式及系統檢視流程。

## 分頁及保存邊界

分頁用穩定識別碼保留目前工作階段嘅篩選、選擇及檢視內容。支援固定、群組、摺疊群組、選單排序、搜尋及四邊位置。關閉前會明確提示目前內容會捨棄，執行中請求可能仍由本機引擎處理。

本機設定只保存導覽資料，最多 24 個分頁。只接受已知路線、唯一識別碼、有效作用中分頁及有效位置。群組名稱最多 48 字。無效資料唔會執行舊操作；目前工作階段仍然可用。儲存失敗會顯示原因及重試操作。檔案路徑、清理計劃、選擇、結果、個人用字及憑證唔會加入分頁快取。

## 原生視窗及清理

Flutter 嘅 Material 控制接駁原生 C++ 視窗操作，包括拖動、最小化、最大化／還原、原生選單及確認關閉。最小尺寸係 800 × 600 邏輯像素，初始尺寸係 1280 × 900。原生調整尺寸及輔助功能仍需要實際 Windows 驗證。

清理沿用既有 CleanupWorkspace，保留伺服器計劃範圍、有效期、原始目標索引、逐項確認、取消競態、結果驗證及指定收據還原。轉分頁唔會捨棄目前操作。

## 驗證及未完成範圍

聚焦測試驗證分頁資料限制、無效快取拒絕、草稿保留及草稿唔會加入已保存資料。既有清理測試驗證目標、收據、取消及最小雙語版面。

呢個基礎未獲生產驗收。48 組真實介面捕捉、原生互動、完整元素清單、設定分頁及編輯器、完整正則建構器、命令面板、鎖定、外觀歷史、獨立趣味程度及對話表情消費者仍待完成。功能清單及排除／不可用數目保持原有狀態。
