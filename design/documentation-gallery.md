# Complete documentation and screenshot gallery

The public website provides a full article index and reader, alongside a dedicated bilingual screenshot gallery. Neither requires a GitHub redirect to read an article. GitHub remains an optional source and issue-reporting destination.

Use official Material Web tabs, buttons and the existing Material search composition. Articles preserve semantic headings, tables, code and accessible links. Images retain their original aspect ratio. Tables and code have their own horizontal scrolling region; the page must not overflow at narrow widths. The gallery uses responsive columns, large readable captions and explicit original-image links.

The initial inventory is forty inspected, unaltered bilingual desktop frames covering five workspaces, two themes, two text sizes and two window sizes. Captions distinguish idle initial viewports from complete interaction proof. Capture time is not asserted without validated provenance.

The Material Designer creation/export/handoff tools were not exposed in this session. This checked-in handoff extends the existing Lit and official Material Web implementation. Runtime layout, keyboard and reduced-motion verification remain required before claiming visual completion.
